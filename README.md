# OLX → Telegram: Apple телефон мониторы

Бұл бот OLX.kz-тегі **Электроника → Телефондар мен аксессуарлар → Мобильді телефондар/смартфондар → Apple** іздеуін мына екі облыста бақылайды:

- Алматы облысы
- Түркістан облысы

Жаңа хабарландыру табылса, әрқайсысын **бөлек** Telegram хабарламасы етіп жібереді. Бір тексерісте екі жаңа пост табылса, екі жеке хабарлама келеді. Бастапқы іске қосуда ескі хабарландырулар жіберілмейді — тек сол сәттен кейін шыққан жаңалары келеді.

## Маңызды шындық

Ноутбуксыз, төлемсіз, шектеусіз және «OLX-те шыққан сәтте» деген төрт талапты қатар қамтамасыз ететін хостинг жоқ. Кез келген серверге ақша, бос лимит немесе ұйқы режимі тән. Бұл дайын бот үздіксіз серверде жұмыс істеуге арналған; сонда тексеру аралығы 25 секунд (ең төмені 20 секунд). Cloudflare қолданылмайды.

Тұрақты, ноутбуксыз жұмыс үшін оны 24/7 Linux серверге немесе өзіңіз бұрыннан иеленетін always-on құрылғыға орналастыру керек. Тегін сервистердің шарттары мен лимиттері жиі өзгереді, сондықтан олар «бірден» деген кепілдік бермейді. Koyeb/Render тәрізді web-service платформаларына арналған `/` health endpoint `PORT` айнымалысы берілгенде автоматты ашылады.

## Қауіпсіздік

Чатқа жіберілген Telegram token жария болып қалды. BotFather ішінде сол token-ді **/revoke** етіп, жаңа token жасаңыз. Token-ді ешқашан GitHub-қа, кодқа немесе чатқа жазбаңыз.

## Іске қосу

1. `.env.example` файлын `.env` деп көшіріп, жаңа token мен Chat ID енгізіңіз.
2. Docker орнатылған серверде жобаның ішінен:

```bash
docker build -t olx-monitor .
docker run -d --name olx-monitor --restart unless-stopped \
  --env-file .env -v olx-monitor-data:/data olx-monitor
```

`--restart unless-stopped` сервер қайта жүктелгеннен кейін ботты қайта бастайды. `olx-monitor-data` базасы бұрын жіберілген хабарландыруларды сақтайды, сондықтан қайталанбайды.

Немесе Docker Compose арқылы:

```bash
cp .env.example .env
# .env ішіне жаңа token жазыңыз
docker compose up -d --build
```

## Docker жоқ Linux сервер

Файлдарды `/opt/olx-monitor` ішіне орналастырып, Python ортасын жасаңыз. `olx-monitor.service` дайын systemd конфигурациясы берілген. `.env` құпия файл болғандықтан оған `chmod 600` орнатыңыз. Қызмет `Restart=always` арқылы апаттан немесе сервер рестартынан кейін өзі қосылады.

## Сервер мүлдем жоқ болса: тегін GitHub Actions

Бұл режимде ноутбук қажет емес. GitHub өз серверінде әр 5 минут сайын бір тексеріс жасайды. Кешігу шамамен 0–5 минут болады, ал GitHub кезегі жүктелгенде ұзағырақ болуы мүмкін.

1. GitHub-та жаңа **public** repository ашыңыз. Public болуының себебі — стандартты Actions минуттары тегін.
2. Осы папкадағы барлық файлды repository-ге жүктеңіз.
3. Repository ішінде `Settings → Secrets and variables → Actions → New repository secret` ашыңыз.
4. `TELEGRAM_BOT_TOKEN` деген secret-ке BotFather берген **жаңа** token-ді енгізіңіз.
5. `TELEGRAM_CHAT_ID` деген secret-ке `6683667749` енгізіңіз.
6. `Actions → OLX Apple monitor → Run workflow` басыңыз.

Бірінші іске қосу тек қазіргі хабарландыруларды базаға белгілейді. Одан кейін пайда болған жаңа посттар жеке-жеке Telegram-ға келеді. `.github/workflows/monitor.yml` автоматты түрде әр 5 минут сайын жұмыс істейді және жіберілген OLX ID-лерін `data/monitor.sqlite3` файлына сақтайды.

Маңызды: GitHub кестесінің ресми ең қысқа аралығы — 5 минут; жоспарланған жұмыс кезекке байланысты кешігуі мүмкін. Public repository 60 күн белсенділік болмаса scheduled workflow-ды автоматты өшіруі мүмкін.

Telegram-да ботқа:

- `/status` — күйі;
- `/pause` — хабарламаларды уақытша тоқтату;
- `/resume` — қайта қосу.

## Шектеулер

OLX ресми жаңа-объявление webhook/API ұсынбайды. Сондықтан бот іздеу бетін қайта тексеру арқылы жұмыс істейді: кешігу — OLX индекстеу уақыты + 20–25 секундтық аралық. OLX бет құрылымын не антибот ережелерін өзгерткен жағдайда парсерді жаңарту керек.
